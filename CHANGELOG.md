# Changelog

## [1.1.1] - 2026-11-10

### Безопасность
- Все экшены контроллера админки требуют право `plugin_datahub_config` и право чтения
  конфигурации, названной в запросе, — как при открытии её в Data Hub. Раньше контроллер прав
  не проверял. Проверка стоит в самом контроллере (`onKernelControllerEvent`) и действует для
  всех его экшенов.

## [1.1.0] - 2026-10-20

### Добавлено
- Назначения ассетов показываются в индикаторе «Идёт выполнение» Data Hub
  (`RunningAssetAssignmentProvider`, один `getItems()` на все конфиги адаптера).
- Настройка `iperson1337_asset_assignment.progress_cache_pool`: пул кеша для прогресса
  выполнения, по умолчанию `opendxp.cache.pool`.

### Исправлено
- Прогресс хранился в `cache.app`, а это файловый кеш в каждом поде. Если воркер
  `asset_assignment` работает в отдельном поде, веб не видел его прогресс: висело начальное
  «0 из N», пока запись не протухала, а отмена из админки чистила запись только у себя. Теперь
  прогресс лежит в общем пуле (Redis).

### Изменено
- Требуется `iperson1337/opendxp-data-hub` ^1.2.
